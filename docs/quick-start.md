# Быстрый старт на Switch (0.5.0)

После первого успешного подключения к роботу приложение запоминает использованные
IP/имя хоста, порт, ключ и полный профиль управления. При следующем запуске
появляется экран **Quick start**:

- **A** — подключиться к последнему роботу с сохранённым профилем.
- **B** — открыть обычный менеджер подключений, выбрать другой адрес или скачать профиль с ПК.
- **Plus** — выйти.

Перед выбором отпустите кнопки. После подключения снова отпустите все кнопки,
затем нажмите deadman для движения. Автоматического начала движения нет;
проверки видео и аварийной остановки работают как обычно. **L+R** возвращает
из управления в менеджер, в том числе если прежний IP сейчас недоступен.

Сохраняется именно профиль успешного подключения. Если скачать новую раскладку,
но ещё не подключиться с ней, быстрый старт продолжит предлагать предыдущую.
Снимок профиля хранится внутри `switch/switchy-op/last-session.json` на SD вместе
с адресом подключения. Компьютер с сервером конфигов для быстрого старта не нужен.
Файл содержит ключ подключения, как и существующий `connections.json`.

Быстрый старт использует снимок профиля в памяти и не заменяет `profile.json`.
Если на стартовом экране выбрать **B**, применяется текущий `profile.json` с SD.
При успешном подключении с другой раскладкой или адресом они становятся новым
последним сеансом. Неудачное подключение не меняет сохранённый сеанс.
Запись выполняется один раз за сеанс, а не при каждом повторном подключении.

Если `profile.json` отсутствует, но последний сеанс сохранился, **A** всё равно
позволяет подключиться. Если отсутствует или повреждён сам `last-session.json`,
приложение открывает обычное меню. Неверная версия файла и данные больше 64 КиБ
отклоняются. При незавершённой замене файла на SD восстанавливается `.rollback`.
Ошибку сохранения видно в сообщениях сеанса; подключение продолжает работать.

При обновлении до 0.5.0 замените только `.nro`, сохранив свои конфиги. На первом
запуске последнего сеанса ещё нет: выберите робота обычным способом и подключитесь.
Меню и работа с настоящей SD требуют проверки на консоли; сохранение, чтение,
обновление и восстановление состояния проверяются тестами на ПК, включая
эмуляцию переименования файлов без перезаписи, как на Switch.

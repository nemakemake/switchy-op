# Установка на Switch

## Видео в версии 0.3.0

Новый нативный клиент показывает H.264-видео, телеметрию и графики.
По умолчанию он читает `rtsp://<адрес шлюза>:8554/robot` и блокирует движение
без живого видео. Настройка источника, `video.json` и режим без камеры описаны
в [инструкции по видео](../docs/video.md). Для запуска с видео используйте hbmenu
с полной памятью через title override; работа декодера в applet mode не проверена.

## Менеджер подключений (версия 0.2.0)

При запуске открывается список серверов. При первом запуске адрес и ключ
импортируются из `profile.json`; далее список хранится отдельно в
`switch/switchy-op/connections.json` на SD. Не заменяйте этот файл при обновлении.

| Кнопка | Действие в списке |
|---|---|
| Крестовина вверх/вниз или левый стик | Выбрать сервер |
| A | Сохранить выбор и подключиться |
| X | Добавить сервер |
| R | Редактировать выбранный |
| Y | Удалить; затем A подтверждает, B отменяет |
| Plus | Выйти из приложения |

При добавлении и редактировании последовательно открывается системная
экранная клавиатура Switch: имя, IP/имя хоста, TCP-порт, ключ. Клавиатура
поддерживает геймпад. Изменения сохраняются только после завершения всех полей;
отмена не меняет запись. Максимум 32 сервера. Ключ скрыт при вводе, но хранится
на SD обычным текстом, как и в профиле.

На экране управления нажмите **L+R**, чтобы отключиться и вернуться к списку.
Перед началом управления отпустите кнопки после выбора сервера, затем заново
удерживайте ZR. При смене Wi-Fi отредактируйте IP нужной записи через R.
Попытка TCP-подключения к одному IP ограничена тремя секундами;
ожидание ответа шлюза — пятью секундами. Для имени хоста поиск DNS может занять
дополнительное время. Во время попытки подключения интерфейс временно ждёт.

Для обновления с 0.1.0 достаточно заменить `switchy-op.nro`.
Свой `profile.json` сохраните. На консоли меню и клавиатура ещё требуют проверки.

## Копирование на SD

Готовый пакет: `dist/switchy-op-switch.zip`.

1. Распакуйте архив в корень SD-карты. Должны получиться файлы
   `switch/switchy-op/switchy-op.nro` и `switch/switchy-op/profile.json`.
2. Откройте `profile.json` и измените `robot.host` с `127.0.0.1` на IP
   компьютера со шлюзом. Укажите `robot.key`, совпадающий с `--key` шлюза.
   Порт TCP по умолчанию — 7000.
3. Запустите шлюз на Linux по [гайду Gazebo](gazebo-quickstart.md).
   Консоль должна иметь сетевой доступ к Linux по TCP 7000 и UDP 7001.
4. На консоли с настроенным homebrew запустите switchy-op через hbmenu.
5. Удерживайте ZR для движения: левый стик — вперёд/назад,
   правый — поворот. Minus включает аварийную остановку, Plus закрывает приложение.

Поставляемый профиль содержит также кнопки симулятора. В режиме Gazebo
свет, гудок и манипулятор не реализованы. После аварийной остановки отпустите
управление и перезапустите шлюз: кнопки сброса в этом профиле нет.

Сборка `.nro` и структура файла проверены; запуск на настоящей консоли
пока не проверялся. При подключении к недоступному адресу экран может временно
замереть. Для первого запуска используйте тестового робота.

## Повторная сборка

В оболочке devkitPro с установленным Switch Development:

```bash
cd native/switch
pacman -S --needed switch-ffmpeg
make -j4
```

Результат — `native/switch/switchy-op.nro`. Профиль можно пересоздать из корня проекта:

```bash
uv run switchy-op export-profile profiles/gamepad.yaml
```

Скопируйте полученный `profiles/gamepad.json` на SD как
`switch/switchy-op/profile.json` и настройте адрес и ключ.

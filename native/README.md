# Нативный клиент (C++ и Nintendo Switch)

Здесь клиент протокола на C++: переносимое ядро и тонкий слой под Switch (libnx). Python-версия в `src/` остаётся эталоном.

```
native/
  core/      переносимое ядро: SHA-256/HMAC, JSON, сокеты, протокол, клиент, раскладка кнопок
  pc/        проверочная программа для ПК
  switch/    приложение под Switch: Makefile и source/main.cpp (libnx)
  check_pc.sh
```

В ядре нет ничего платформенного, кроме `net.cpp` (Winsock на Windows, обычные сокеты на Switch). Исключения и RTTI не используются, так как в сборке для Switch они выключены.

## Проверка на ПК

Нужны `g++` с поддержкой C++20 и `uv`.

```bash
bash native/check_pc.sh
```

Скрипт собирает клиент, сверяет HMAC-SHA256 с Python на границах блоков, запускает настоящий Python-шлюз и прогоняет через C++ клиент весь сценарий: рукопожатие с подписью, движение, кнопки (с переключателем по реальному состоянию), удержание, длинное действие, блокировки и обрыв связи. Ожидаемый итог: `OK: 0 check(s) failed`.

## Сборка для Switch

1. Установите devkitPro с компонентом Switch Development. Установщик (`devkitProUpdater-3.0.3.exe`) просит права администратора и показывает мастер, в нём выберите папку на нужном диске.
2. Откройте оболочку MSYS2 из devkitPro (убедитесь, что задана переменная `DEVKITPRO`).
   Установите видеобиблиотеки: `pacman -S --needed switch-ffmpeg`.
3. Если путь к проекту содержит нелатинские символы, соберите из копии в папке с латинским путём: инструменты devkitPro могут не справиться с такими путями.

```bash
cd native/switch
make
```

Результат: `switchy-op.nro`.

## Установка на консоль

Скопируйте на SD-карту:

```
switch/switchy-op/switchy-op.nro
switch/switchy-op/profile.json
```

Профиль получается из YAML командой:

```bash
uv run switchy-op export-profile profiles/gamepad.yaml
```

В профиле укажите адрес шлюза (`robot.host`, `robot.port`) и ключ (`robot.key`, он должен совпадать с ключом шлюза). Запускайте из hbmenu. Кнопка Plus закрывает приложение и не отдаётся профилю.

Названия кнопок в профиле это подписи на Switch (A, B, X, Y). Правый стик поворот, левый вперёд и назад, ZR «мёртвая рука».

В версии 0.4.0 профиль можно загрузить с ПК по Wi-Fi, без извлечения SD:
`switchy-op serve-profiles --directory profiles --key my-download-key`, затем
**L** в менеджере подключений Switch. [Инструкция](../docs/profile-sync.md).

## Что проверено, а что нет

Проверено: всё в `core/` (на ПК, против настоящего шлюза).

Сборка для Switch проверена 2 ноября 2026 через devkitPro/devkitA64 и libnx:
получен `switchy-op.nro`, проверены заголовки NRO0 и ASET. Пакет для SD-карты
находится в `dist/switchy-op-switch.zip`.

На консоли пока не запускалось. Требуют проверки опрос сокетов и контроллеров,
подключение к шлюзу и восстановление связи. Подключение к недоступному адресу
блокирующее: экран на это время может замереть.

В версии 0.3.0 добавлен прототип H.264-видео и графического экрана с сенсорным
переключением графиков и полного экрана. Настройка и ограничения: [видео](../docs/video.md).
Без `video.json` видео включено и требуется для движения; для работы без камеры
положите на SD `video.json` с `{"enabled": false}`.

Не сделано: вибрация и гироскоп Joy-Con. Видео и сенсорное управление требуют
проверки на настоящей консоли.
